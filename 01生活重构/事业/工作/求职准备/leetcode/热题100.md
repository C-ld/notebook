
# 哈希

## 1. 两数之和 S

- 题目

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** _`target`_  的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

- 易错点
	- 没考虑到重复元素情况

- 解答

扫描一遍，每一个数存储对应的“差值”到 map，扫每个数检查是否在 map 的 key 里，map 的值存储 index。
```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> map;
        map[target - nums[0]] = 0;
        vector<int> res = {0, 0};
        for (int i = 1; i < nums.size(); i++) {
            if (map.find(nums[i]) != map.end()) {
                res[0] = map[nums[i]];
                res[1] = i;
                break;
            }
            map[target - nums[i]] = i;
        }
        return res;
    }
};
```


## 49. 字母异位词分组 M

- 题目
给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。

- 易错点
	- 注意操作优化

- 解答
简单，先排序，然后以排序的字符串作为key即可。
```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, int>map;
        vector<vector<string>> res;
        for(auto str : strs){
            string key = str;
            sort(key.begin(), key.end());
            if(map.find(key) == map.end()){
                map[key] = res.size();
                res.push_back(vector<string>());
            }
            res[map[key]].push_back(str);
        }
        return res;
    }
};
```



## 128. 最长连续序列 M
- 题目

给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

- 解法
一开始想的是记录每一段长度的左值右值，然后每次检查是否拓展。
后来发现正确的思路是，记录所有数，然后以每一个没有 i-1 的 i 作为序列开始，去看 i+1 是否存在记录中，这样子来”数“序列的长度，妙啊。

- 易错点
	- 遍历时通过set遍历，不要通过num，不然容易超时


```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int>set;
        for(int& i:nums){
            set.insert(i);
        }
        int maxlen = 0;
        for(int i:set){
            if(set.find(i-1) != set.end())continue;
            int tmp = i+1, cnt = 1;
            while(set.find(tmp) != set.end()){
                tmp++;
            }
            cnt = tmp - i;
            if(cnt > maxlen)maxlen = cnt;
        }
        return maxlen;
    }
};
```


# 双指针

## 283. 移动零 S
- 题目
给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**请注意** ，必须在不复制数组的情况下原地对数组进行操作。

- 解法

左指针找到数组中第一个0，然后右指针往后扫，扫到一个非零数就交换一下即可

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int lp = 0, rp = 0, n = nums.size();
        while(lp < n && nums[lp] != 0){
            lp++;
        }
        if(lp == n)return;
        rp = lp + 1;
        while(rp < n){
            if(nums[rp] != 0){
                nums[lp++] = nums[rp];
                nums[rp] = 0;
            }
            rp++;
        }
        return;
    }
};
```


## 11. 盛最多水的容器 M

- 题目
给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明：**你不能倾斜容器。

- 解答
一阶思路：计算第一个高度到剩余所有高度的最大水量，第一个高度记录为左侧最大高度，后续就是对每一个比左侧最大高度的高度，计算最大水量（简化计算是从最右端开始，每一个如果比它小就计算，其实这里也可以考虑维护一个比它小的最大值，比它大则判断是否更新最大值后停止扫描）

二阶思路：
本质上，要让水量最大，就是要让（距离、max（hl, hr））两者之一尽可能大。如果取最左最右为初始，则已经满足最大距离，如果当前水量不是最大水量，那么只能减小距离来获得更大的 max(hl, hr)。所以这就变成了一个如何减小距离使得水量尽可能大的问题，显然，应该是 l、r 中数值小的那一侧进行改变。

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int l, r, hl, hr, res = 0, n = height.size(), tmp;
        l = 0;
        r = n-1;
        while(l < r){
            hl = height[l];
            hr = height[r];
            if(hl < hr){
                tmp = hl * (r-l);
                l++;
            }
            else{
                tmp = hr * (r-l);
                r--;
            }
            res = res < tmp ? tmp : res;
        }
        return res;
    }
};
```


## 15. 三数之和 M
- 题目
给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。

- 解法
一开始只想着仿照两数之和用哈希来做，也就是一层循环下套一个两数之和，但是发现这样计算效率非常低（内存操作量也很大）。

后来发现问题还是出在大量的“查重”上。为了避免查重，先排序就是一个很重要的步骤。排序之后，只要保证每个遍历的元素与上一次不同，即可保证答案不重复。后续二元组的查找因为是有序的，就可以利用双指针，达到 $O(N^2)$  的复杂度。 

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> res;
        sort(nums.begin(), nums.end());
        int n = nums.size();
        int prex = nums[0] - 1;
        int x, l, r;
        for(int i=0;i<n-2;i++){
            x = nums[i];
            if(x == prex)continue;
            //second loop(double ptr)
            l = i+1; r = n-1;
            while(l < r){
                int sum = x + nums[l] + nums[r];
                if(sum > 0){
                    r--;
                    while(l < r && nums[r] == nums[r+1])r--;
                }
                else if(sum < 0){
                    l++;
                    while(l < r && nums[l] == nums[l-1])l++;
                }
                else{
                    res.push_back({x, nums[l], nums[r]});
                    r--;
                    while(l < r && nums[r] == nums[r+1])r--;
                    l++;
                    while(l < r && nums[l] == nums[l-1])l++;
                }
            }
            prex = nums[i];
        }
        return res;
    }
};
```

## 3. 无重复字符的最长子串 M

- 题目

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长子串** 的长度。

- 解法

滑动窗口算是比较简单的问题了，略

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int len = s.size(), tmpl;
        int res = 0;
        int left = 0, right = 0;
        unordered_set<char>c_set;
        while(right < len){
            char c = s[right];
            if(c_set.find(c) != c_set.end()){
                tmpl = right - left;
                res = res < tmpl ? tmpl : res;
                while(s[left] != c){
                    c_set.erase(s[left]);
                    left++;
                }
                left++;
            }
            else{
                c_set.insert(c);
            }
            right++;
        }
        tmpl = right - left;
        res = res < tmpl ? tmpl : res;
        // cout << typeid(s.at(0)).name();
        return res;
    }
};
```

## 438. 找到字符串中所有字母异位词 M

- 题目

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

- 解法


```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int>c_cnt(26, 0);

        vector<int>res;
        if(s.size() < p.size()){
            return res;
        }

        int a = 'a', n = s.size();
        for(auto c : p){
            c_cnt[c-a]++;
        }

        int l = 0, r = p.size() - 1;
        for(int i=l;i<r;i++){
            c_cnt[s[i]-a]--;
        }
        while(r < n){
            c_cnt[s[r]-a]--;
            int k = 0;
            for(auto i : c_cnt){
                k = k | i;
            }
            if(k == 0){
                res.push_back(l);
            }
            r++;
            c_cnt[s[l]-a]++;
            l++;
        }
        return res;
    }
};
```

## 560. 和为 K 的子数组 M

- 题目

给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 _该数组中和为 `k` 的子数组的个数_ 。

子数组是数组中元素的连续非空序列。

- 解法

这题的难点在于，k 和数组元素可以取负值。所以不能用滑动窗口做。
其次，遇到这种连续子元素求和，应该快速想到利用 `前缀和` 作为解题工具，减少计算量。

最后，针对各种 special case，需要分别分析，谨慎对待。（比如注释中，oc2里，多个 pre\[i\] 值相同的情况，就决定了本题不能用 hashset，而是应该用 hashmap。


```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        int len = nums.size();
        int s = 0;
        int res = 0, tmp;
        // occasion 1: pre[i] = k
        // occasion 2: pre[j] - pre[i] = k, j > i
        // pre[j] - pre[i] = k, j > i => pre[j] = pre[i] + k
        // by scanning pre[x], record pre[x] + k in hashmap
        // value is the time the key is computed.
        unordered_map<int, int>map;

        for(auto& i : nums){
            s += i;
            i = s;
            tmp = s + k;
            if(s == k)res++;
            if(map.find(s) != map.end())res += map[s];
            map[tmp]++;
        }
        return res;
    }
};
```


## 239. 滑动窗口最大值 H（感觉是 M）

- 题目

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回 _滑动窗口中的最大值_ 。


- 解法（不看题解一次过hh）

非严格单调栈即可（a<=b）。单调栈的问题在于，如果有两个一样大的最大值，只会保留一个在栈中，窗口排出最大值时就会导致错误，所以有几个最大值存几个在栈里，就解决了。

```cpp
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        vector<int>res;
        deque<int>win;
        int len = nums.size();
        int l = 0, r = k;
        for(int i=l; i<r; i++){
            int num = nums[i];
            while(!win.empty() && win.back() < num){
                win.pop_back();
            }
            win.push_back(num);
        }
        res.push_back(win.front());
        while(r < len){
            int num = nums[r];
            if(win.front() == nums[l]){
                win.pop_front();
            }
            l++;
            while(!win.empty() && win.back() < num){
                win.pop_back();
            }
            win.push_back(num);
            res.push_back(win.front());
            r++;
        }
        return res;
    }
};
```

## 76. 最小覆盖子串 H

给你一个字符串 `s` 、一个字符串 `t` 。返回 `s` 中涵盖 `t` 所有字符的最小子串。如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""` 。

- 解法

没啥说的，滑动窗口+位运算 yyds。唯一需要注意的是，map\[ \] 的使用，即便没有赋值，只要调用了就会增加这个key，所以一个细节问题就会导致很大的错误。

```cpp
class Solution {
public:
    string minWindow(string s, string t) {
        string res = "";
        int lidx = -1, tlen = s.size() + 1;
        if(s.size() < t.size()){
            return res;
        }

        unordered_map<char, int>map;
        for(char c : t){
            if(map.find(c) == map.end())map[c] = -1;
            else map[c]--;
        }
        
        int l = 0, r = 0, len = s.size();
        while(r < len){
            char cr = s[r];
            if(map.find(cr) != map.end()){
                map[cr]++;
                if(map[cr] == 0){
                    int tmp = 0;
                    for(auto i : map){
                        tmp = tmp | i.second;
                    }
                    if(tmp >= 0){
                        while(true){
                            char cl = s[l];
                            if(map.find(cl) != map.end()){
                                map[cl]--;
                                if(map[cl] < 0){
                                    if(tlen > r-l+1){
                                        lidx = l;
                                        tlen = r-l+1;
                                    }
                                    l++;
                                    break;
                                }
                            }
                            l++; 
                        }
                    }
                }
            }
            r++;
        }
        if(lidx != -1){
            res = s.substr(lidx, tlen);
        }
        return res;
    }
};
```

## 53. 最大子数组和 M

- 题目

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组**

是数组中的一个连续部分。

- 解法

不难，但是细节比较多，尤其像一些“子数组不能为空的情况要尤为注意”。思路是记录临时和，每加一个右值，判断一次是否大于当前最大的和。如果临时和是负数，其+任何值都会使其更小，所以临时和重置为 0 然后继续加右值。

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int maxsum = -10000, len = nums.size(), r = 0;
        int tmp = 0;
        while(r < len){
            int nr = nums[r];
            tmp += nr;
            if(tmp > maxsum)maxsum = tmp;
            if(tmp < 0){
                tmp = 0;
            }
            r++;
        }
        return maxsum;
    }
};
```


## 56. 合并区间 M

- 解法

没啥说的，不难。

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        vector<vector<int>>res;
        int curl = intervals[0][0], curr = intervals[0][1];
        for(auto& i:intervals){
            if(i[0] <= curr && i[1] > curr){
                curr = i[1];
            }
            else if(i[0] > curr){

                curl = i[0];
                curr = i[1];
            }
        }
        res.push_back({curl, curr});
        return res;
    }
};
```


## 189. 轮转数组 M

- 解法

```cpp
class Solution {
```

## 238. 除自身以外数组的乘积 M

- 题目

给你一个整数数组 `nums`，返回 数组 `answer` ，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积 。

请 **不要使用除法，**且在 `O(n)` 时间复杂度内完成此题。

- 解法

不难，算前缀积即可

```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int len = nums.size();
        vector<int>prem(len);
        int p = 1, t = 1;
        for(int i=0;i<len;i++){
            p *= nums[i];
            prem[i] = p;
        }
        vector<int>res(len);
        for(int i=len-1;i>0;i--){
            res[i] = prem[i-1] * t;
            t *= nums[i];
        }
        res[0] = t;
        return res;
    }
};
```

## 73. 矩阵置零 M

- 题目

给定一个 `_m_ x _n_` 的矩阵，如果一个元素为 **0** ，则将其所在行和列的所有元素都设为 **0** 。请使用 **原地** 算法。

- 解法

主要难在常数级的额外空间，但是其实思路是递进的，在想到用行数+列数个空间记录哪些行哪些列为0时，进一步节省空间只能利用原数组中的某行某列进行记录，再用两个变量记录这一行一列是否为0即可。还是比较巧妙的。

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        bool ifr0 = false, ifc0 = false;
        int rowl = matrix.size(), coll = matrix[0].size();
        for(int i=0;i<rowl;i++){
            if(!ifc0 && matrix[i][0] == 0){
                ifc0 = true;
            }
        }
        for(int i=0;i<coll;i++){
            if(!ifr0 && matrix[0][i] == 0){
                ifr0 = true;
            }
        }
        for(int i=1;i<rowl;i++){
            for(int j=1;j<coll;j++){
                if(matrix[i][j] == 0){
                    matrix[0][j] = 0;
                    matrix[i][0] = 0;
                }
            }
        }
        for(int i=1;i<rowl;i++){
            if(matrix[i][0] == 0){
                for(int j=1;j<coll;j++){
                    matrix[i][j] = 0;
                }
            }
        }
        for(int j=1;j<coll;j++){
            if(matrix[0][j] == 0){
                for(int i=1;i<rowl;i++){
                    matrix[i][j] = 0;
                }
            }
        }
        for(int i=0;i<rowl;i++){
            if(ifc0){
                matrix[i][0] = 0;
            }
        }
        for(int i=0;i<coll;i++){
            if(ifr0){
                matrix[0][i] = 0;
            }
        }
        return;
    }
};
```

## 54. 螺旋矩阵 M

- 题目

给你一个 `m` 行 `n` 列的矩阵 `matrix` ，请按照 **顺时针螺旋顺序** ，返回矩阵中的所有元素。

- 解法

不难，一遍过。用总数控制循环次数，或者用每次“拐弯”之后，是否是已经访问过的方式来判断是否结束循环均可。

```cpp
class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        int up = 0, down = matrix.size()-1, left = 0, right = matrix[0].size()-1, n = matrix.size()*matrix[0].size();
        int x = 0, y = 0, stt = 0;
        vector<int>res;
        for(int cnt=0; cnt<n; cnt++){
            res.push_back(matrix[x][y]);
            if(stt == 0){//to right
                if(y < right){
                    y++;
                }
                else{
                    stt = 1;
                    x++;
                    up++;
                }
            }
            else if(stt == 1){//to down
                if(x < down){
                    x++;
                }
                else{
                    stt = 2;
                    y--;
                    right--;
                }
            }
            else if(stt == 2){
                if(y > left){
                    y--;
                }
                else{
                    stt = 3;
                    x--;
                    down--;
                }
            }
            else if(stt == 3){
                if(x > up){
                    x--;
                }
                else{
                    stt = 0;
                    y++;
                    left++;
                }
            }
        }
        return res;
    }
};
```

## 48. 旋转图像 M

- 题目

给定一个 $n × n$ 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在 **原地** 旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要** 使用另一个矩阵来旋转图像。

- 解法

没啥难的，奇数偶数分开计算即可，看看老代码好了。

*float 类型强制转换到 int 时只保留整数部分*

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size(), nval;
        int mid = n/2;
        if((n & 1) == 1){
            int dx, dy;
            for(int i = 0; i <= mid; i++){
                for(int j = 0; j < mid; j++){
                    dx = mid - i;
                    dy = mid - j;
                    nval = matrix[i][j];
                    matrix[i][j] = matrix[mid + dy][mid - dx];
                    matrix[mid + dy][mid - dx] = matrix[mid + dx][mid + dy];
                    matrix[mid + dx][mid + dy] = matrix[mid - dy][mid + dx];
                    matrix[mid - dy][mid + dx] = nval;
                }
            }
        }
        else{
            float m = (float)mid - 0.5, dx, dy;
            for(int i = 0; i < mid; i++){
                for(int j = 0; j < mid; j++){
                    dx = m - i;
                    dy = m - j;
                    nval = matrix[i][j];
                    matrix[i][j] = matrix[int(m + dy)][int(m - dx)];
                    matrix[int(m + dy)][int(m - dx)] = matrix[int(m + dx)][int(m + dy)];
                    matrix[int(m + dx)][int(m + dy)] = matrix[int(m - dy)][int(m + dx)];
                    matrix[int(m - dy)][int(m + dx)] = nval;
                }
            }
        }
    }
};
```

编写一个高效的算法来搜索 `m x n` 矩阵 `matrix` 中的一个目标值 `target` 。该矩阵具有以下特性：

- 每行的元素从左到右升序排列。
- 每列的元素从上到下升序排列。

- 解法

一开始想的太复杂了，没有很“高效”地利用行列递增的效果。实现也过于复杂，实际做题时，高效和简洁至少要占一个吧。如果一时间没想到高效而简洁的写法，先写简洁的，再尝试优化。

本题的基础思路是按行/列筛查，然后二分。实际上我们就是通过行/列的两端值确定是否在我们的搜索范围。由此可以进一步思考得到，如何最大化利用两端值。最终应该可以思考出利用右上角的值吧。（也很巧妙，如果 t 比它大，则 t 不在它这一行，如果 t 比它小，则不在它这一列。）


```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size(), n = matrix[0].size();
        int x = 0, y = n - 1;
        while (x < m && y >= 0) {
            if (matrix[x][y] == target) {
                return true;
            }
            if (matrix[x][y] > target) {
                --y;
            }
            else {
                ++x;
            }
        }
        return false;
    }
};

```

```cpp
            n--;

        ListNode* slow = head;
        while(fast->next){
            fast = fast->next;
            slow = slow->next;

        slow->next = slow->next->next;
        return head;
```

```cpp
            tail->next = new Node(tmp->val);
            tail = tail->next;
            map[tmp] = tail;
            tmp = tmp->next;

            tmp = tmp->next;
            tail = tail->next;

};
```
