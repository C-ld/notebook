trade_when

This operator can be used in order to change Alpha values only under a specified condition and to hold Alpha values in other cases. It also allows to close Alpha positions (assign NaN values) under a specified condition:

Trade_When (x=triggerTradeExp, y=AlphaExp, z=triggerExitExp)

If triggerExitExp > 0, Alpha = nan;

Else if triggerTradeExp > 0, Alpha = AlphaExp;

else, Alpha = previousAlpha

Use Trade_when Operator to reduce turnover of alpha . Can reduce turnover when used with price volume alphas .

if_else 实现：

trade_when (triggerTradeExp, AlphaExp, triggerExitExp)
if_else(triggerExitExp, nan_out(1,lower=2), if_else(triggerTradeExp, AlphaExp, previousAlpha))

trade_when(alpha>1, alpha, -1) 等于 if_else(alpha>1, alpha, previousAlpha)

trade_when(alpha>1, alpha, alpha<-1) 等于 if_else(alpha<-1, nan_out(1, lower=2), if_else(alpha>1, alpha, previousAlpha))
