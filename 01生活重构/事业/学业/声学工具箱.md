### kraken 使用方法
![[Pasted image 20250214150856.png]]
- .env 和 .flp 是环境文件
- .prt、.mod 和 .shd 是kraken生成文件
	- .prt 是过程输出日志，可以查看过程是否正确运行
	- .mod 存储了 kraken 计算出的特征值和特征函数，是二进制文件，无法直接阅读，可以用 read_modes 函数阅读
	- .shd 是 kraken 计算出的声压数据，是二进制文件，无法直接阅读。可用 read_shd 读取声压数据，用 plotshd 画传播损失图

![[Pasted image 20250214151421.png]]
![[Pasted image 20250214151433.png]]



```c
% 以 MunkK 为例（一个深海信道）

clc;
kraken MunkK;  %运行kraken

figure;
% 画图默认单位是 m，可以通过如下方式改成 km
% global units;
% units = 'km'
plotshd MunkK.shd.mat; %画传播损失

% 某距离随深度变化的传播损失
figure;
plottld('MunkK.shd.mat', 50); % 画 50km 处的传播损失（跟 units 无关）

% 某深度随距离变化的传播损失
figure;
plottld('MunkK.shd.mat', 50); % 画 50km 处的传播损失（跟 units 无关）

% 看 mode
figure;
plotmode('MunkK.mod', 0, [1 2 3]);

% 如何读取声场 read_shd
[ PlotTitle, PlotType, freqVec, freq0, atten, Pos, pressure ] = read_shd( 'MunkK.shd.mat' );
size(pressure) 
% 1 1 501 1001
% PlotTitle & PlotType are msg for painting
% freqVec, freq0, atten ? 没用到
% **Pos 结构体**：
%   s: source
%       z: depth
%   Nsz: Number of source depth
%   r: receiver
%       z: depth
%       ro:倾斜阵
%       r: range 距离
% **Pressure 结构体**
```

pressure 实际是一个五维参数 `Output is a 5-D pressure field p( Nfreq, Ntheta, Nsd, Nrd, Nrr )` 频率数、角度数、声源深度、接收器深度、接收器距离

写 env 文件
```c
% 写 env
[ TitleEnv, freq, SSP, Bdry, Pos, Beam, cInt, RMax, fid ] = read_env( 'MunkK.env', 'KRAKEN' );
fclose all;
write_env( 'MunkK2', 'KRAKEN', TitleEnv, freq, SSP, Bdry, Pos, Beam, cInt, RMax);
```

首先仿真舰船辐射噪声的时域信号，然后先对信号做 STFT，分时间窗处理，然后对每个时间窗里的每个频点乘上声压的幅度即可得到实际声压（水听器的接收信号）。

但是如果要模拟线列阵做波束形成的话，相位应该也要调整？

说到底，多通道是为了波束形成，既然已知某距离的声压，可以直接计算对于每个频点的波束响应，最后通过：海洋环境噪声模拟 + 某方向波束的波束响应 * 对应方向的目标信号（kraken信道模拟后的）

- 舰船辐射噪声分频点进行 kraken 计算（KRAKEN）
	- STFT
	- kraken 预先计算各频点的声压值
		- 预设目标位置，循环中用 read_env 和 write_env 来修改频率
		- 用一个数组 Arr 记录所有频点在目标距离和深度的声压值
	- 利用 Arr 和计算出的声信号的每个时间窗下的频点相乘，得到每个时间窗下，每个频点的实际幅值
- 波束形成模拟
	- 对每个角度的波束，分别计算 海洋噪声+信号\*对应的波束响应，得到波束形成结果（时间窗数——角度——频率），也可看每一角度的时频图（LOFAR）
	- 对所有时间窗求和，可得到 角度-频率 图，即波束图

# 官方手册
## 整体架构

![[Pasted image 20250213142557.png]]

KRAKEN程序实际上是称为Acoustics Toolbox的完整建模工具包的一部分，其结构如图4.1所示。除了KRAKEN正常模式模型之外，还有一个1）射线/光束跟踪模型BELLHOP，2）FFP（光谱积分）SCOOTER和3）时域FFP模型SPARC 

这些模型以用户提供的环境文件（ENV）作为输入来描述问题。该文件对所有模型具有相同的格式。PLOTSSP可用于生成环境文件中定义的声速曲线的图表。

然后，这些模型生成一个包含计算压力场的二进制“阴影”文件（SHDFT）。PLOTFIELD可用于将压力转换为**传输损失**，并在**范围和深度上生成传输损失的彩色或灰色阴影图**。PLOTSLICE程序用于沿着固定的接收器深度绘制场的切片。还有其他程序可用于使用阴影文件进行匹配场处理，以计算检测概率或检测半径。

有一些实用程序可用于在NRL阴影文件格式和SACLANTCEN格式（TONRL和TOSAC）之间进行转换。这允许使用PLOTFIELD和PLOTSLICE绘制SACLANTCEN模型以进行模型间比较。还有一些实用程序可用于将阴影文件转换为ASCII格式（TOASC）并返回其原始二进制格式（TOBIN）。这些程序允许您通过传输ASCII文件在具有不兼容二进制文件的计算机之间传输文件。

虽然基本结构如图4.1所示，但每个模型都有其独特的额外绘图程序。例如，BELLHOP射线模型产生射线，因此它有一个射线绘图程序，而KRAKEN正常模式产生模式，因此它有一个模式绘图程序。在本章中，我们将重点描述KRAKEN组件，然而，其他模型也将（简要）讨论。

Group 1 mode computations:
- KRAKEN
	- 求解模式并将它们写入磁盘。允许使用弹性介质，但材料衰减在弹性介质中被忽略。
- KRAKENC
	- KRAKENC 是 KRAKEN 的一个版本，用于在复平面中找到特征值。KRAKEN 使用微扰理论获得特征值的虚部，而 KRAKENC 则精确地计算复特征值。
	- KRAKENC 的运行速度大约慢 3 倍，但对于泄漏模式计算或在弹性介质中考虑材料衰减是必要的。在内部，KRAKENC 用等效反射系数替换弹性层。因此，你不能使用 KRAKENC 来查看弹性层内的场。
- KRAKEL
	- 与 KRAKENC 类似，但也为弹性介质计算弹性位移和应力。KRAKEL 很少被使用，并且往往不会保持最新状态。

G2：basic plotting routines:
- PLOTSSP
	- 绘制声速剖面图
- PLOTMODE
	- 绘制选择的模式
- PLOTGRN
	- 绘制特定源/接收器组合的深度分离波动方程的格林函数。
- PLOTTLR
	- 绘制传输损失与距离的关系图。
- PLOTTLD
	- 绘制传输损失与深度的关系图。
- PLOTTRI
	- 绘制用于3-D场计算的三角形元素。

G3：FIELD COMPUTATIONS:
- FIELD
	- 计算垂直阵列上特定范围内以及一系列源深度上的场。阵列中的单个水听器可能偏离垂直方向。范围相关性通过绝热或单向耦合模式理论处理。
- FIELD3D
	- 三维变SSP的计算字段，使用绝热模态理论。 

G4：PLOTTING ROUTINES THAT USE G3 PROGRAM OUTPUT:
- PLOTFIELD
	- 绘制平面或仰角的传输损失，即（x，y）图或（r，z）图。
- PLOTSLICE
	- 通过从多个阴影文件中提取切片，绘制传输损耗与距离曲线的叠加图。
- PLOTRAYXY
	- 绘制三维场计算过程中产生的高斯光束的射线路径。

计算领域（GROUP III）的各种程序仅PLOTFIELD或特殊用户程序（例如：
歧义表面）。PLOTTLR和PLOTTLD计算字段在内部，因此不需要从FIELD跑。

_****如何运行 KRAKEN****_  
1. 首次开始？查看 [CLINK.COM](https://clink.com/) 以进行整个软件包的编译和链接。
2. 按照 KRAKEN.HLP 中的说明为你的问题创建环境文件。
3. 运行 KRAKEN（或 KRAKENC）。在 VAX 上，这可以通过输入 @KRAKEN 文件名或 SUBMIT KRAKEN/PAR = 文件名来完成，其中 “文件名” 是环境文件。KRAKEN.HLP 文件详细说明了 KRAKEN 和 KRAKENC 之间的区别。
4. 现在你有几个选择（所有 GROUP II 程序）：  
    a. 绘制传输损失：@PLOTTLR 文件名  
    b. 绘制模式：@PLOTMODE 文件名  
    c. 绘制声速剖面（实际上，这甚至可以在运行 KRAKEN 之前完成）：@PLOTSSP 文件名 
    d. 绘制作为距离和深度函数的压力场。这是一个两步过程：  
    @FIELD 文件名  
    @PLOTFIELD 文件名
通常，在运行每个命令文件之前，你必须修改它以提供每个程序的帮助文件中描述的适当输入。一旦由 KRAKEN 或 KRAKENC 创建了模式，你可以按任意顺序或根据需要多次运行上述绘图程序。

#### kraken.hlp
https://oalib-acoustics.org/website_resources/AcousticsToolbox/manual/node47.html
KRAKEN是主程序。它接受一个环境文件，计算模式，并将它们写入磁盘以供其他模块使用。还会生成一个打印文件，与用户输入相呼应。
KRAKENC是KRAKEN的复杂算术版本（因此KRAKENC中的C）。通过在复杂域中工作，损失机制，如冰散射和物质吸收可以“精确地”包括在内，而不是摄动地包括在内。此外，还可以计算泄漏模式。这种非摄动处理的代价是速度减慢大约4倍。这个因素主要代表复杂算术和真实算术之间的差异。
如果在KRAKENC中使用Twersky散射选项，可能会进一步减慢2倍或更多。Twersky散射函数的计算可能需要大量的CPU时间；足以成为计算模式成本的主要部分。KRAKEN摄动地合并散射，对Twersky散射成本不太敏感。
KRAKEN不允许弹性介质因材料衰减而产生损失。因此，对于衰减弹性介质，应使用KRAKENC。
