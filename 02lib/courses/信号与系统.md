## 1.2 信号的定义

人们通常以声、光、电为载体传送或接收消息

定义1：信号是消息的表现形式或传送载体（狭义）
消息是信号的具体内容

定义2：信号是随一些参数变化的某种物理量（广义）

## 1.3 信号的分类

信号主要分为四大类：
- 确定信号：信号在定义域上的每一点都有确定的函数值
![[Pasted image 20230726093408.png]]
- 随机信号：不满足确定信号的定义的信号
PS：注意，这里的确定信号的“确定”实际上是可预测的意思，也可以说是函数值的确定性


- 连续时间信号：信号的定义域为连续区间，通常以 x(t) 表示，t 属于 R 。
![[Pasted image 20230726093804.png]]
- 离散时间信号：信号的定义域为一些离散点，通常以 x\[k] 表示，k 属于 I。

微分方程的分类：
- 常微分方程：方程中未知函数 y 为一元函数
- 偏微分方程：u = u(x, y)，含有偏微分的方程

- 线性：未知函数 y 及其各阶导数都是 一次 的
- 非线性：不是线性的

微分方程的解，就是代入 微分方程 使方程 成为恒等式 的 **函数**。

通解：n 阶微分方程，含有 n 个相互独立的（不可合并的） 任意常数 的解。
初值条件：确定了 任意常数 的条件
特解：确定了通解中 任意常数 后的解

### 5、信号抽样定理的工程应用

#### 转化过程
![[Pasted image 20230902180131.png]]
工程当中，是先将连续信号进行抽样保持，然后抽样得到离散时间信号。最后通过对离散时间信号进行量化编码，得到数字信号。

实际元件：A/D转换器
![[Pasted image 20230902180315.png]]
![[Pasted image 20230902180320.png]]

#### 工程难点
![[Pasted image 20230902180543.png]]
实际工程当中，很多信号都不满足带限条件。因为很多信号都是有限的，那么它的频谱就像左下图，会无限延伸。这个时候有两种办法：第一种，直接对原信号进行采样，这种采样不可避免会发生混叠，产生混叠误差。第二种，先把原信号通过抗混低通滤波器，滤除高频分量得到一个近似的带限信号。然后对带限信号进行采样和还原效果都较好，但是无法还原原信号（截断误差）。

一般认为截断误差比混叠误差要小：
![[Pasted image 20230902181035.png]]
所以工业上一般还是采用抗混低通滤波器，滤波器的截止频率是采样频率的一半。

对于未知限度的信号，可以先高频采样，看看有没有 (pi, 0) 之前有没有余量。有的话就把采样频率拉低一些。
