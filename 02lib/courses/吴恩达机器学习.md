面对无法通过明确的编程来解决问题（感觉本质是因为规律未知），如网络搜索、识别人声、自动驾驶。所以我们让机器自己学习如何去做这些事情。

### 2.1 什么是机器学习

"Field of study that gives computers the ability to learn without being explicitly programmed."

一般来说，给学习算法学习的机会越多，学习的就越好。

一般机器学习算法可以分为以下两种：
- Supervised learning 有监督
	应用最多，进步和创新也最迅速
- Unsupervised learning 无监督
- Reinforcement learning 强化学习

### 2.2 2.3 监督学习

监督下的学习，指的是学习从X到Y或者输入到输出的映射算法。其关键特征是，你给算法提供正确的例子来进行学习。最后算法能举一反三，并对输入给出一个合理的预测或猜测输出。

应用列举：
![[Pasted image 20230624104123.png]]

监督学习算法也可以分为两类：
- 回归算法 Regression
从无限多的可能数字中预测一个数字，例如房价预测问题中的房价。

- 分类算法 Classification
e.g 肿瘤预测
从有限多的可能类别中预测最有可能的类别。

### 2.4 2.5 无监督学习
训练数据 input 没有任何输出标签 labels，算法不被期望直接给出某一个标签或是结果，而是希望找到数据中存在的某种结构或规律。

- 聚类算法 Clustering（Google News）
把未标记的数据放到不同的集群中。有趣的是，这种算法会自己找出具有哪些相同特征的数据应该被分为一组。

- 异常检测 Anomaly detection（金融系统中的欺诈监测）
找到数据中的异常值

- 维度降低 Dimensionality reduction
把一个大数据集压缩到一个小得多的数据集，并且尽量少地丢失信息

### 4.1 4.2 梯度下降
梯度下降及其变式是机器学习中一种非常重要的算法，其用于获取更好的参数以使得代价的值尽可能小

![[Pasted image 20230703145147.png]]
算法：
- 首先，给所有参数设定初值
- 然后，改变参数来使得代价函数值减小
- 重复上一步，直到我们达到或者接近一个最小值（局部最小，不一定是全局）

本质上就是找当前代价函数变化率最大的下降方向——梯度（切线方向），按切线方向

算法实现过程：
获取代价函数对每一个参数在当前点的导数值，该值的含义为
- “正负”——随着该参数的增加，代价函数将会增加还是减少
- “大小”——随着该参数的增加，代价函数值的变化速率
此时我们用当前参数的 **取值** 减去 **学习率** 乘以 **导数值**，即可得到该参数的下一个迭代版本

对各个参数同时重复以上过程，直到代价函数值不发生改变或增大，注意，各参数的更新应该是同时的，这才是求导的意义所在。
![[Pasted image 20230703150915.png]]
![[Pasted image 20230703153027.png]]
**求导的意义在于获取方向和更新速率。
从导数正负上看，如果导数为正，那么参数就应该取一个更小的值；
那么具体该往多小取呢？这就要看导数的大小了，一般来说，导数值越大说明这里越抖，那么就可以走得更快一些，从直接上也可以判断坡度抖说明离平地还比较远。当接近最小值时，导数的大小会减小，这就会“减缓步幅”，从而达到进一步靠近最小值的目的。妙啊**

如何选择一个更好的学习率alpha：
- 太小，学得太慢
- 太大，学过了，而且会在一定范围内越来越过（因为导数值大小会增大）

以上的梯度下降算法被称为 “Batch”梯度下降，因为它的每一次学习（计算迭代参数值）都是通过涵盖所有的训练集数据的计算得到的。

Batch——Each step of gradient descent uses all the trainning examples.

### 2.1 2.2 特征缩放 Feature Scaling

对于线性回归的系数向量w而言，如果某一特征 w_i 对应的 x_i 的范围相比其他 x_j 小得多，那么 w_i 就很可能是一个较大值。同时，x_i 的微小变化就会对 y 值产生巨大影响。这些特征就会导致在梯度下降时会**花费更多的时间**来找到全局最小值。所以一般我们考虑把 x_i 缩放到一个可比的范围（例如0~1），然后再求取使代价函数最小的特征向量 w 和参数 b 。
![[Pasted image 20230708232342.png]]
![[Pasted image 20230708232405.png]]

#### 特征缩放的一些常用方法
- 除以最大值（最好范围是单符号的）
映射到(0,1)，但是由于最小值的差异

- 均值归一化（Mean normalization）
减去平均值再除以极差，因为映射后是一个在 \[-1, 1\] 中间、长度为1的一个范围，所以比较**通用**。

- Z分数归一化（Z-score normalization）
类似均值，不过除以的是标准差

#### 什么时候采用特征缩放

一般来看，如果某一特征范围的均值或极差与其他特征相差过大，就需要对其进行缩放。

![[Pasted image 20230719135204.png]]


### 2.3 2.4 梯度下降的收敛

recall一下，梯度下降旨在通过代价函数对假设函数的常系数参数进行更新，以期获得一个更小的代价函数值，所以我们说的梯度下降的收敛，本质上就是代价函数值在一定次数迭代后收敛于某一个值。

#### 判断收敛的方法
- 学习曲线（learning curve）
堪称收敛可视化，通过画出代价函数值随梯度下降迭代次数的增加而产生的变化，来直观地观察收敛情况。

- 自动收敛测试（automatic convergence test）
其实就是设定一个合适的阈值，当某次迭代产生的代价函数值与上一个值的差小于该阈值，则直接停止训练。

![[Pasted image 20230719140438.png]]

#### 学习率的选择

本质上就是选一个然后不断调整，一般可以考虑从0.01开始，设置一定的迭代次数后画出代价函数变化图像，如果不收敛除以10，如果可以收敛乘以3，不断尝试后找到一个收敛较好且速度较快的学习率。

### 1.2 逻辑回归 logistic regression

使用最广泛的分类问题算法。

分类问题其实有一个隐含的上下文，也就是数据是存在类别的。而类别又存在界限，所以我们真正希望的不是像回归一样找到某个输入在R上的映射目标，而是去找到不同类别之间的“界限”。有了界限，那么给输入数据划分到相应类别就是意见自然而然的事了。

首先我们需要认识一个函数——logistic function，又称 sigmoid function
![[Pasted image 20230720210458.png]]
可以看到，sigmoid函数本身就有一点“分割”的感觉。函数本身也具有很多便利的性质（定义域、值域），同时其函数值可以作为一种概率看待。
![[Pasted image 20230720210942.png]]

那么实际进行分类问题的时候我们当然不是只采用logistic函数，而是会将logistic函数套在线性回归的假设函数上面，以实现一个关于输入特征的多项式到目标类别的映射。实际训练过程中，我们仍然是在求解假设函数中的常系数参数向量。

### 1.3 决策边界 Decision boundary

### 2.1 逻辑回归中的代价函数

首先需要对我们已知的一个概念“代价函数”进行一个拆解：对于 m 个训练样例，代价函数计算“每一个样例的模拟输出和实际标签值的差距”的平均值。那么对于线性回归问题，我们可以简单采用一个“差平方的一半”的形式作为线性回归在每一个样例点上的**损失函数 Loss function**。
![[Pasted image 20230721231603.png]]

而对于逻辑回归，由于引入了 sigmoid 函数，映射关系发生了变化，原本的损失函数就不好用了。就像上图中，因为其计算方式和我们对分类问题预期的不同，代价函数将会出现多个局部最优值，这会对我们的训练产生阻碍。因此，我们会选择一个更合适的损失函数，使得代价函数成为一个凸函数。

- 当 y=1 时，假设函数的值比1越小，损失越大，所以取负的对数，趋近于1时，损失趋近于0
- 当 y=0 时，假设函数的值比0越大，损失越大，所以取1-f的对数，趋近于0时，损失趋近于0

### 4.2 解决过拟合问题
如何解决过拟合问题？通常有三种方法：
1、收集更多训练数据。这是最直接有效的办法（尤其对于小规模数据），但是很多情况下我们并没有更多的数据可以使用

2、特征选择 select features，即选择一部分的特征，或者说移除一部分特征。这一方法往往可以用在多项式回归中移除一些高阶项，或者在特征数量过多时移除一些不那么重要的特征。当然，这种方法的风险就在于可能会删去一些有意义的、有用的特征。
![[Pasted image 20230723233539.png]]

3、正则化 regularization。简单来说，通过减小高阶多项式参数的数量级来减小其对假设函数的影响，不过这一影响在定义域范围内还是会在远端变大，这种方法可以在不删减特征的前提下避免过拟合。所以个人感觉，如果多项式高阶项的参数在正则化后很小且训练集正确率很高，其实可以考虑删去高阶项再重新拟合。
![[Pasted image 20230723234142.png]]


### 4.3 正则化 Regularization

我们已经了解到，正则化问题，其实就是用来解决多项式/多特征中，一些高阶项/冗余项导致的过拟合问题，而过拟合问题，本质上是因为高阶项和干扰项的系数过大，所以其对假设函数的影响就过高。那么正则化就是在不删减高阶项/特征的前提下，减少这种影响的方法。

正则化的实现方式也很直接，既然是因为系数过大导致的问题，我就让系数小。怎么小呢？就是在代价函数中加入一个“惩罚量”——正则化表达式。那么在实际训练中，高阶量的系数一旦变大，整个代价函数就会快速增加，但是我们在训练过程中是在追求让整个代价函数变小。所以代价函数小了，系数自然就小了。

### 1.3 需求预测 Demand Prediction

一个关于神经网络的具体事例：
对于一个给定的商品，请预测它是否会成为畅销商品？

比如说你收集了一些不同的衬衫数据，包括他们是否是畅销品和他们的价格。这也是学习算法的输入特征。
如果按照之前学习的知识，显然对于分类问题我们会采用逻辑回归模型。
![[Pasted image 20230726164508.png]]
但是在神经网络中，我们把原来的假设函数值 f(x) 记为 a（激活activation），即神经元（neuron）向下游其他神经元输出的信号。
也就是说，一个神经元会接受输入的 x ，神经元通过假设函数计算出结果 a 。对于这个事例，a 的值是 输入 x 对应的商品成为畅销品的概率。

![[Pasted image 20230726173955.png]]
首先，如果我们对这个这个问题进行建模，比方说我们认为直接影响一件T恤成为畅销品的因素有3个，即人们是否买得起、它的知名度、以及产品质量。那么就可以构造一个具有三个神经元的层（layer），这三个神经元分别根据需要的输入特征计算自己的输出值，再将其送给下一层。一般地，我们把最左边的输入特征向量称为输入层（Input layer）。那么在这里，下一层只有一个神经元，它会根据三个 activation 计算出我们需要的最终结果并进行输出，所以它所在的这一层也被称为输出层（output layer）。那么在实际的应用中，由于我们往往不清楚中间层的神经元和哪些输入特征有关，我们会给每个神经元访问所有输入特征的权限。那么现在图就变成了这样：
![[Pasted image 20230726174621.png]]

那么最终成型的神经网络如下：
输入层是输入特征组成的单独层
中间层（可以有多个）将输入值计算出 激活值（activation value）并输出给下一层。由于最终训练好的模型并不会让用户感知每一个中间输出的实际值，所以我们称其为 隐藏层（hidden layer）

![[Pasted image 20230726175904.png]]

一个更直观的评价是，在线性回归和逻辑回归中，我们一般需要通过特征工程来获得一个更好的算法表现，或者说获得一些更合适的输入特征。但是对于神经网络来说，它不需要你再去手动设计特征，而是会自己学习构造新的特征来解决整个问题。这也是为什么神经网络能成为现在世界上最强大的算法的原因之一。

![[Pasted image 20230726181656.png]]
那么，一个显而易见的问题就是，如果我需要利用神经网络来解决问题，我需要多少个隐藏层？每一层又需要多少个神经元？这两个问题统称为神经网络架构（Neural Network architecture）问题。后面会对其进行讲解。

- 不同的网络层从输入往输出编号从小到大，输入层是第 0 层
