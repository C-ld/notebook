## JDK 8 

```sh
apt search openjdk
apt install openjdk-8-jdk
java -version
```

注：如果本机已经安装了 java，并且是用的 update-alternatives，可以如下操作：
```bash
#检查当前选项
update-alternatives --config java

#安装java8
apt install openjdk-8-jdk
update-alternatives --install /usr/bin/javac javac /usr/lib/jvm/java-1.8.0-openjdk-amd64/bin/javac 1

#切换java环境
update-alternatives --config java
```

## rocketMQ

如果用 docker 部署，需要保证 虚拟机 分配的内存，否则实例无法运行。
如果用本机部署，需要注意，就装 JDK 8，高了低了都不行。

```sh
wget https://dist.apache.org/repos/dist/release/rocketmq/5.2.0/rocketmq-all-5.2.0-bin-release.zip

apt install unzip
unzip rocketmq-all-5.2.0-bin-release.zip

cd rocketmq-all-5.2.0-bin-release/bin

### start Name Server
nohup sh bin/mqnamesrv &

### check whether Name Server is successfully started
tail -f ~/logs/rocketmqlogs/namesrv.log
The Name Server boot success...

### start Broker
nohup sh bin/mqbroker -n localhost:9876 &

### check whether Broker is successfully started, eg: Broker's IP is 192.168.1.2, Broker's name is broker-a
tail -f ~/logs/rocketmqlogs/broker.log
The broker[broker-a, 192.169.1.2:10911] boot success...

### shutdown rocketMQ
sh bin/mqshutdown broker
sh bin/mqshutdown namesrv

```

## eventbridge

从 https://github.com/apache/rocketmq-eventbridge?tab=readme-ov-file

```sh
mkdir eventbridge
cd eventbridge

wget https://dlcdn.apache.org/rocketmq/rocketmq-eventbridge/1.1.0/rocketmq-eventbridge-1.1.0-bin-release.zip
这个好像直接下载挺慢的，建议本地下载完上传服务器

unzip rocketmq-eventbridge..

```

项目下运行
```sh
cd /root/rocketmq-eventbridge/dist/target/rocketmq-eventbridge-dist-1.1.0/rocketmq-eventbridge
bash bin/eventbridge.sh start
```

配置 config 下 properties 文件
```
rocketmq.namesrvAddr=localhost:9876
```

运行
```sh
bash bin/eventbridge.sh start
```

The default log directory is ~/logs/rocketmq-eventbridge.log. You can modify log.path and app.name in config/application.properties to observe whether the service starts normally through the log.


关闭
```
ps -ef | grep eventbridge
kill ***
```

测试
```sh

```

	#add 2 rows below:
	export GOROOT=/usr/local/go
	export PATH=$PATH:$GOROOT/bin
	#then save & quit

go version

go env | grep GOPROXY

go env -w GO111MODULE=on
