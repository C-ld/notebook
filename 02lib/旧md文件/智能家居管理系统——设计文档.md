###  2.3 数据结构

Device 智能设备（具体功能模块可以通过继承方式实现，每个成员变量会有相应的get，set方法）
```c++
class Device{
	string name;  //设备名
	int type;    //设备类型，1-4分别为灯、开关、传感器、所，0未设定
	virtual bool isOpen();  //虚函数，查看设备开关状态
	...
}
```

Room 房间
```c++
class Room{
	string name;  //房间名
	int numOfDev;    //设备数量
	vector<Device>devlist;   //设备列表
	...
}
```

Place 场所
```c++
class Place{
	string name;    //场所名
	int numOfDev;     //设备数量
	int numOfRoom;     //房间数量
	vector<Device>devlist;  //设备列表（这些设备在场所内但不在房间内）
	vector<Room>devlist;   //房间列表
}
```


## 3 系统模块设计

### 3.1 整体功能设计

1. 实现用户注册、登录功能，用户注册时需要填写必要的信息并验证，如用户名、密码要求在6字节以上，手机号的格式验证，并保证用户名和手机号在系统中唯一，用户登录后可以进行以下操作。

2. 用户登录后可以创建场所，然后在场所里创建智能设备（中间可以加一级，就是场所里先创建房间，然后在房间里创建智能设备）

3. 设备类型至少支持以下几种
	- 灯（支持开关和亮度调节）
	- 开关
	- 传感器（温湿度等信息查看）
	- 门锁（开关门状态上报）

4. 提供列表信息查看设备信息、设备状态和上报信息

5. 提供可视化界面展示以上信息，可以在房间户型图（上传图片）上摆放设备，或者提供画图功能画出场所图

6. 可以在手机上查看

### 3.2 子模块功能设计

#### 3.2.1 用户信息管理模块

该模块需要实现的功能有：
- 用户注册及合法注册校验
- 用户登录及登录校验（可拓展自动登录功能）
- 用户信息页显示及个人信息修改

#### 3.2.2 智能设备管理模块

该模块需要实现的功能有：
- 场景的创建、查询、修改和删除
- 房间的创建、查询、修改和删除
- 智能设备的创建、查询、修改和删除
- 房间户型图上传、智能设备在户型图上的摆放
