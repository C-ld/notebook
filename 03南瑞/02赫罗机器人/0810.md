
## 🗺️ FRD 系统学习路径：后端 ↔ 前端 ↔ Hermes Agent 交互逻辑

### 一、先看架构全景图

整个系统是一个**安全生产/工作票管理**具身智能体应用，核心架构如下：

```
┌──────────────┐     HTTP/SSE(MCP)     ┌──────────────────┐
│  Hermes Agent│ ←──────────────────→  │  Runtime Server  │
│  (AI 大脑)   │                       │  (后端业务平台)   │
└──────┬───────┘                       └────────┬─────────┘
       │  OpenAI API                             │ WebSocket
       │  (chat)                                 │ + HTTP
       ▼                                         ▼
┌──────────────┐     HTTP API          ┌──────────────────┐
│Voice Gateway │ ←──────────────────→  │  前端 UI         │
│ (语音入口)    │                       │  (Screen_G1)     │
└──────────────┘                       └──────────────────┘
       │
       ▼
  麦克风/扬声器
```

三条主线：
- **语音线**：用户说话 → Voice Gateway → Hermes Agent → 回复 → TTS 播报
- **控制线**：明确口令（如"签到"、"取消"）→ Voice Gateway 直送 Runtime → 场景执行
- **展示线**：Runtime 场景执行 → WebSocket 推送 → 前端实时更新

#### 第 2 步：深入 Runtime 后端核心

这是理解所有交互逻辑的**中枢**，按以下顺序阅读：

**2.1 启动与依赖注入** — [runtime/bootstrap.py](file:///d:/workspace/python/FRD/runtime/bootstrap.py)
- `RuntimeContext` 类创建所有核心组件并注入到 `SessionService`
- 关键：`DeviceGateway`、`FaceRecognitionRepository`、`TicketService`、`SessionRegistry`、`BindingRegistry`

**2.2 会话管理** — [session/service/session_service.py](file:///d:/workspace/python/FRD/session/service/session_service.py)
- `create_session()` / `ensure_session()` — 创建/确保业务会话
- `upsert_binding()` — **核心**：登记 Hermes 会话 ↔ Runtime 会话的绑定关系
- `resolve_runtime_session()` — 通过 hermes_session_id 反查 Runtime 会话

**2.3 单会话运行时** — [runtime/service/session_runtime.py](file:///d:/workspace/python/FRD/runtime/service/session_runtime.py)
- `SessionRuntime` 是每个会话的核心引擎，包含：
  - `ScenarioEngine` — 场景执行引擎
  - `LobbyWatcher` — 大厅迎宾（后台轮询人脸）
  - `VoiceIntentHandler` — 语音意图处理
  - `WebSocketNotifier` — 前端推送
- 重点看 `on_ui_connected()` — 前端连接时的初始化逻辑

#### 第 3 步：理解 Voice Gateway（语音入口）的交互逻辑

这是理解**语音 → Hermes → Runtime**整条链路的核心。

**3.1 主循环** — [voice/service/voice_gateway_bridge.py](file:///d:/workspace/python/FRD/voice/service/voice_gateway_bridge.py)

这是整个系统最核心的交互逻辑文件，阅读重点：

```
run_forever() 主循环:
  1. voice.hear()           → ASR 语音识别
  2. _is_noise_voice_text() → 噪声过滤
  3. _handle_shutdown()     → 关机指令
  4. _handle_scenario_busy()→ 场景中控制词（继续/结束/取消）→ 直送 Runtime
  5. _handle_local_command()→ 本地明确口令 → 直送 Runtime
  6. _reject_if_hermes_busy()→ Hermes 忙碌时拒收
  7. _handle_new_conversation()→ 新任务/换票
  8. _enqueue_hermes()      → 排队送入 Hermes Agent
```

**关键分层逻辑**：
- **明确口令**（"签到"、"安全交底"、"取消"等）→ 本地 `local_command_router` 处理，**不经过 Hermes**，直送 Runtime
- **模糊/对话**（"今天怎么样"、"为什么进不了场"）→ 送入 Hermes Agent

**3.2 Runtime HTTP 客户端** — [voice/service/runtime_voice_client.py](file:///d:/workspace/python/FRD/voice/service/runtime_voice_client.py)
- 封装了所有调用 Runtime HTTP API 的方法
- 启动时：`ensure_session()` + `upsert_binding()` 登记绑定
- 运行时：`push_voice_command()`、`heartbeat_voice_gateway()` 等

#### 第 4 步：理解 Hermes Agent 与 MCP 交互

这是理解 **AI Agent 如何调用后端**的关键。

**4.1 Hermes 客户端** — [agent/repository/hermes_client.py](file:///d:/workspace/python/FRD/agent/repository/hermes_client.py)
- 通过 OpenAI 兼容 API 与 Hermes 对话
- 关键方法 `_with_frd_session_context()`：**每轮对话自动注入 `[FRD] hermes_session_id=xxx`**，供 Agent 调用 MCP 工具时使用
- 会话策略：稳定绑定 `vg-{session_id}`，多轮复用

**4.2 MCP 工具定义** — [agent/mcp/inprocess_mcp.py](file:///d:/workspace/python/FRD/agent/mcp/inprocess_mcp.py)
- 定义了 Agent 可调用的工具：`frd_get_session_status`、`frd_run_scenario`、`frd_init_session` 等

**4.3 MCP 工具实现** — [agent/mcp/runtime_tools.py](file:///d:/workspace/python/FRD/agent/mcp/runtime_tools.py)
- `RuntimeTools` 直接调用 `SessionService`（进程内，零网络开销）
- 每个工具都有 `_by_hermes` 版本，通过 `_resolve()` 将 `hermes_session_id` 转为 `runtime_session_id`

**4.4 Hermes 技能配置** — [hermes-skills/](file:///d:/workspace/python/FRD/hermes-skills)

**4.5 绑定注册表** — [session/repository/binding_registry.py](file:///d:/workspace/python/FRD/session/repository/binding_registry.py)
- `BindingRegistry` 维护 `hermes_session_id → runtime_session_id` 的映射
- 这是**共享 MCP（单 Hermes 多网关）**的核心：Agent 通过 `hermes_session_id` 找到正确的 Runtime 会话

### 三、核心数据流总结

```
用户说话
    │
    ▼
VoiceGatewayBridge.run_forever()
    │
    ├── 明确口令（签到/取消/继续…）
    │   └── RuntimeVoiceClient.push_voice_command()
    │       └── Runtime HTTP API
    │           └── SessionRuntime.handle_voice_text()
    │               └── ScenarioEngine.run()
    │                   └── WebSocketNotifier → 前端 UI
    │
    └── 模糊/对话
        └── HermesClient.chat(text + [FRD] hermes_session_id)
            └── Hermes Agent 推理
                └── 调用 MCP 工具（如 frd_run_scenario）
                    └── RuntimeTools → SessionService → SessionRuntime
                        └── 场景执行 → WebSocket → 前端 UI
            └── 回复文本
                └── VoiceGatewayBridge TTS 播报
```
