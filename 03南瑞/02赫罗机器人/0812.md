## Screen_G1 项目完整分析

---

### 一、项目定位

宇树 G1 人形机器人**胸屏** Web 前端。通过 WebSocket 接收后端状态快照，按全局相位（GlobalPhase）驱动 5 个场景视图切换，语音交互由后端 Runtime 处理，前端纯展示。

---

### 二、技术栈

| 组件 | 版本 | 用途 |
|------|------|------|
| Vue 3 | `^3.5.38` | 视图框架 |
| TypeScript | `~6.0` | 类型系统 |
| Vite | `^8.0` | 构建工具 |
| Pinia | `^3.0.4` | 状态管理 |
| Vue Router | `^5.1` | 单路由占位 |
| Element Plus | `^2.14.2` | 少数 UI 控件（仅 Home.vue 和部分旧组件使用） |
| lodash-es | `^4.18.1` | debounce（仅 PageSettings.vue 使用） |

### 四、全局相位 → 视图映射

这是整个应用的核心，定义在 `App.vue` 的 `scenarioStore.viewKey` computed：

```
GlobalPhase      → viewKey        → 渲染组件
────────────────────────────────────────────────
IDLE             → "idle"         → IdleView
WORK_WAITING     → "idle"         → IdleView
DONE             → "idle"         → IdleView
LOBBY            → "lobby"        → LobbyView
OFFERING         → "ticket_confirm" → WorkLeaderSignInView
SCENARIO         → "scenario"     → Home.vue (对话历史)
RESULT           → "result"       → ResultView
```

### 五、5 个视图详细分析

#### 5.1 IdleView — 空闲/待机

```
触发相位：IDLE、WORK_WAITING、DONE

┌──────────────────────────────────────────────────┐
│  智能展示系统  [空闲]        服务状态：在线  时间  │  ← header
│                                                  │
│                                                  │
│              ┌──────────┐                        │
│              │ 脉冲光环  │                        │
│              │  G1 Logo │                        │
│              │          │                        │
│              └──────────┘                        │
│                                                  │
│              待机中 / 已唤醒                       │
│              等待语音唤醒... / 正在聆听...         │
│              [guide_prompt 文字]                  │
│                                                  │
└──────────────────────────────────────────────────┘
```

**两种子态（由 `voice.isAwake` 驱动）：**

| 状态 | 光环颜色 | 标题 | 提示文字 |
|------|:---:|------|------|
| 未唤醒 | 蓝色 `rgba(30,100,200)` | "待机中"（灰色） | "等待语音唤醒..." |
| 已唤醒 | 绿色 `rgba(34,150,80)` | "已唤醒"（绿色） | "正在聆听，请说话..." |

语音数据中断 30 秒后自动回落到未唤醒（voiceStore 内置超时）。

数据来源：
- `voice.isAwake` → 唤醒/待机切换
- `scenarioStore.scenarioLabel` → 顶栏相位标签
- `scenarioStore.prompt?.text` → 引导文字（如"请说'开始巡检'"）
- `gatewayStore.online && scenarioStore.wsConnected` → 服务在线状态

**特性：独立时钟**，每秒更新 `currentTime`。

#### 5.2 LobbyView — 大厅迎宾

```
触发相位：LOBBY

两种模式切换：
  identityPreview.visible && imageUrl 存在
  ├── 是 → 全屏人脸画面（人脸照片 + 叠加层）
  └── 否 → 全屏扫描动画（扫描线 + 用户图标 + 等待文字）
```

**全屏人脸模式下的 4 层叠加：**

```
┌──────────────────────────────────────────────┐
│  [header: 大厅迎宾 · 识别中]                  │  ← 半透明浮层

│      │                            │           │
│      │     摄像头实时人脸画面       │           │
│      │                            │           │
│      │                            │           │
│      ├────────────────────────────┤           │
│      │ 深色渐变遮罩                │           │
│      ├────────────────────────────┤           │
│      │ [已识别] 张三                │  ← face-meta
│      │ 迎宾识别                    │

│      │ 或 💬 XXX，您好             │  ← identity_confirmed
```

**4 个子状态（由 lobbyStore.subState 驱动）：**

| 子状态 | 叠加层内容 |
|--------|------|
| `lobby_idle` | 无（全屏扫描动画模式） |
| `person_detected` | 蓝点脉冲 + "正在识别身份，请正对摄像头…" |

**注意：此视图无任何用户交互按钮**，签到确认全依赖语音（后端 Runtime 监听"签到"关键词）。

### 六、WebSocket 协议

仅 **4 种**消息类型，`state_change` 是核心：

| 类型 | 用途 | 处理函数 |
|------|------|----------|
| `state_change` | **全局相位快照**（包含 global / lobby / scenario / ticket / result / prompt / identity_preview / participants / recording） | `applyStateChange()` |
| `system` | 页面样式设置 | `settingsStore.updateSettings()` |
| `new_message` | 新对话消息 | `dialogStore.addMessage()` |
| `update_message` | 更新已有消息 | `dialogStore.updateMessage()` |
| `delete_message` | 删除消息 | `dialogStore.deleteMessage()` |

**`state_change` 数据结构（`StateChangePayload`）：**

```typescript
{
  global: GlobalPhase        // IDLE | LOBBY | OFFERING | SCENARIO | RESULT | WORK_WAITING | DONE
  awake?: boolean            // 语音唤醒状态
  gateway_online?: boolean   // 网关在线状态
  lobby?: LobbyStatePayload  // 大厅迎宾子状态 + 文案
  scenario?: ScenarioInfo    // 场景名 + 当前子状态 + 进度
  payload?: {
    ticket?: TicketPayload          // 工作票信息
    identity_preview?: IPayload     // 身份预览（null=清除）
    participants?: { required[], recognized[], names{} }
    recording?: { duration_sec, transcript }
    result?: { success, message, recognized[], scenario_name }
    prompt?: { text, expect[], person_name }
  }
}
```

**一次 `state_change` 消息可以同时更新多个维度**——global 切换相位的同时带着 ticket / preview / result 数据，前端一次 `applyStateChange` 全部写入对应 Store。

**seq 去重机制：** `lastSeq` 记录最近序号，跳过乱序到达的旧消息。

### 八、数据流完整链路

```
后端 Runtime
    │
    │  WebSocket 推送 JSON
    ▼
websocketService.onmessage → JSON.parse
    │
    ▼
App.vue handleWsMessage(msg)
    │
    ▼
scenarioStore.handleMessage(msg)
    │
    ├── type === 'state_change'
    │   └── applyStateChange(msg)
    │       ├── seq 去重检查
    │       ├── currentGlobal = data.global → viewKey 响应式更新
    │       ├── gatewayStore.setOnline(gateway_online)
    │       ├── voiceStore.applyVoiceListening(awake)
    │       ├── lobbyStore.applyState(lobby)
    │       ├── ticket / prompt / result → scenarioStore 自身 ref
    │       ├── identityPreviewStore.applyPayload / clear
    │       └── scenarioInfo → scenarioStore 自身 ref
    │
    │   → App.vue currentView computed 响应
    │   → <component :is> 销毁旧视图 / 创建新视图
    │   → 新视图 onMounted 读取各自 Store
    │
    ├── type === 'new_message' / 'update_message' / 'delete_message'
    │   └── dialogStore 增删改 → Home.vue 气泡列表响应
    │
    └── type === 'system'
        └── settingsStore.updateSettings() → CSS 变量更新
```

### 九、技术要点

| 要点                    | 说明                                                   |
| --------------------- | ---------------------------------------------------- |
| **路由不参与页面切换**         | Router 只有一个占位路由 `/`，所有视图切换由 `<component :is>` 动态组件完成 |
| **seq 去重**            | `applyStateChange` 检查 `msg.seq < lastSeq` 跳过旧消息      |
| **null vs undefined** | `identity_preview: null` 表示主动清除，`undefined` 表示不改变    |
| **语音状态超时**            | `voiceStore.setListening(true)` 启动 30s 定时器，到时自动回落    |
| **IdleView 独立时钟**     | 每秒 `setInterval` 更新，在 Phase 切换时组件销毁自动清理              |
| **Home.vue 独立 WS 消费** | 不再自己连 WS，消息通过 scenarioStore 中继                       |
